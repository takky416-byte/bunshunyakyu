# ブログ記事 執筆ルール(共通・全ブログ向け)

文春野球友の会サイト(yakyu.bunshun.jp)へブログ記事を自動投稿するツール
(`post_blog.py`)に読み込ませる原稿を、ChatGPT等に書いてもらうための共通ルールです。

**このファイルの内容を、記事を書いてもらうたびにChatGPTへの指示(プロンプト)の
冒頭にそのまま貼り付けてください。** その後ろに、書いてほしい記事のテーマ・
タイトルの方向性・トーンなど、その記事固有の指示を続けて書けばそのまま使えます
(ブログごとに別ファイルを用意する運用はしていません)。

このルールに沿わない出力は、自動投稿時に書式崩れ・改行の欠落・画像が入らない
などの不具合の原因になります。

## 出力全体の形式

- 1行目に記事タイトルを1行で書く。
- 2行目は空行にする。
- 3行目以降が本文。
- 見出し(下記「見出し」を参照)以外の目的で `#` を段落の先頭に書かない。
  箇条書き記号(`-`・`*`・`1.`)は使わない(このツールでは解釈されず、記号が
  そのまま文字として表示されてしまう)。

## 段落

- 段落と段落の間は、必ず1行の空行で区切る。
- 1つの段落の中で改行したい場合は、そのまま改行してよい(自動的に改行として
  扱われる)。`<br>` と明示的に書く必要はない。

## 文字装飾

太字・斜体・下線には次のHTMLタグを使う。Markdownの `**太字**` / `*斜体*` /
`__下線__` は使わない(特に `__下線__` は下線ではなく太字と解釈されるので注意)。

- 太字: `<b>太字にしたい部分</b>`
- 斜体: `<i>斜体にしたい部分</i>`
- 下線: `<u>下線にしたい部分</u>`
- 組み合わせ可: `<b><u>太字+下線の見出し</u></b>`

## 引用

段落の先頭を `> ` にすると引用(blockquote)になる。複数行にわたる引用は、
継続行の先頭にも `> `(または、行間を1行空けたいだけの場合は単独の `>`)を付ける。

## 見出し

- 段落の先頭を `# `(半角シャープ+半角スペース)にすると、本物の見出し
  (記事本文中の中見出し)になる。例: `# 弘治元年　安芸国・厳島`
- 見出しは前後を必ず空行で区切る(他の段落と同じ)。
- このサイトの本文エディタは見出しのレベルを1つしか持たないため、`##`のように
  `#`を複数書いても同じ見出しになる(章・節のような複数階層の使い分けはできない)。
- 見出しの直前には、通常の段落間より少し広めの間隔が自動的に入る。
- 見出しには文字装飾(`<b>`/`<i>`/`<u>`)を付けないこと(既にひとつの見出しとして
  強調表示されるため)。
- 見出しを使わない(地の文を`<b><u>見出し</u></b>`のような太字下線の疑似見出しで
  済ませる)ブログの場合は、単にこの記法を使わなければよい。

## 画像の挿入

- 本文中の画像を入れたい位置に、**画像だけの行**として `![説明](ファイル名)`
  と書く(前後を必ず空行で区切る)。説明文は省略可: `![](img1.jpg)`。
- ファイル名は、実際にその記事のフォルダに置く画像ファイル名と一致させる
  (ChatGPTが画像そのものを生成するわけではなく、人間が別途用意してこの記事
  フォルダに同じファイル名で置く運用のため)。
- 本文中に複数枚挿入する場合は `img1.jpg`、`img2.jpg` のように連番にする。
- 記事の一番上に出る「ヘッダー画像(アイキャッチ)」は本文中の画像とは別物で、
  本文には含めない(`header.jpg` など、別のファイル名で別途用意する)。

## タグについて

- 興味関心タグは、記事の本文には一切書かない。タグはブログ(記事シリーズ)
  ごとにあらかじめ決められた固定の一覧が自動で設定される仕組みになっており、
  本文中に書いても使われない(タグの一覧はそのブログの `tags.txt` で管理する)。

## 出力形式のチェックリスト(ChatGPTへの指示の最後に付けると効果的)

- [ ] 1行目はタイトルのみ、2行目は空行になっているか
- [ ] 箇条書き記号(`-`/`1.`)を使っていないか
- [ ] 見出し以外の場所で行頭に `#` を書いていないか
- [ ] 太字/斜体/下線は `<b>`/`<i>`/`<u>` タグを使っているか(`**`/`__`不使用)
- [ ] 段落と段落の間に空行が1つ入っているか
- [ ] 画像は `![説明](ファイル名)` の形式で、前後が空行になっているか
- [ ] 本文中にタグの記載がないか
