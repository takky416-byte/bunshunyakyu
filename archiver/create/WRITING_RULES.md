# 執筆ルール: IT野球選手名鑑

対象フォルダ: `archiver/create/`
興味関心タグ(自動設定・本文には書かない): `選手名鑑`, `IT野球選手名鑑`
(このフォルダ直下の `tags.txt` に設定済み。記事ごとに変える必要はない)

IT基本用語(ITパスポート試験シラバス相当)を、プロ野球選手名鑑風に紹介する
読み物です。出力フォーマットの共通ルール(文字装飾・画像挿入・タグの扱いなど)は
`archiver/WRITING_RULES_COMMON.md` を参照(そちらを先に、このファイルを後に
ChatGPTへの指示として貼り付ける)。

## タイトル行(1行目)

```
IT野球選手名鑑 #連番　用語名　――キャッチコピー。
```

- 全角スペースで区切る。
- 連番は3桁(例: `#051`)。直前に投稿した記事の続き番号にする。
- キャッチコピーは「――」で始め、体言止めか「。」で終わる一文。用語の特徴を
  野球っぽく言い換える(例:「一人倒れても、試合は止めない。」)。

## 本文の構成(この順番・見出しで固定)

1. `![](img1.jpg)` — 本文の一番最初に、画像を1枚だけ挿入する
2. `<b><u>IT野球選手名鑑 #連番</u></b>`
3. 用語名(装飾なし、1行)
4. キャッチコピー(装飾なし、1行。タイトル行の「――」以降と同じ文言)
5. `<b><u>基本プロフィール</u></b>`
   `登録名：` `背番号：` `守備位置：` `投打：` `所属：` `出身：` の6項目を
   1行ずつ(「項目：値」の形式)。背番号は連番と同じ数字。所属・出身は
   用語のイメージに合わせた架空のチーム名・学校名などを創作する。
6. `<b><u>選手紹介</u></b>`
   3段落。①試合中のエピソード風の書き出し → ②その用語の仕組みの説明 →
   ③注意点・限界、という流れ。
7. `<b><u>シーズン成績</u></b>`
   その用語らしい指標を6項目、「項目名　値」の形式で1行ずつ(項目名と値の
   間は全角スペース)。実在の野球成績名をもじった、用語の特徴を表す指標にする。
8. `<b><u>スカウティングレポート</u></b>`
   3段落。①長所 → ②短所・注意点 → ③現実的な使いどころ、という流れ。
9. `<b><u>IT解説</u></b>`
   3〜4段落。1段落目の冒頭で `<b>用語名</b>` のように太字にして正式に定義する。
   類似・対比される用語との違いにも触れる。
10. `<b><u>関連選手</u></b>`
    関連するIT用語を2つ。それぞれ `<b><i>用語名</i></b>` の次の行に1行で説明。
11. 区切り線(全角ダッシュのみの行):
    ```
    ────────────────────
    ```
12. 定型の免責文(引用。文言は毎回このまま使う):
    ```
    > この選手名鑑は、IT基本用語をプロ野球選手名鑑風に紹介する試みです。
    >
    > ITパスポートの試験シラバスから用語を抽出しているので、読んでいれば自然とITパスポートに合格すること請け合いです。
    >
    > なお、この選手名鑑は、生成AIをフル活用して執筆しています。ご了承ください。
    ```

## トーン・文体

です・ます調。IT解説部分は資格試験の参考書のように正確に、それ以外(選手紹介・
スカウティングレポート)は野球中継の実況・解説のような比喩を交えた文体にする。

## その他の注意点

- 過去記事の「関連選手」欄などで既に取り上げた用語と、内容が極端に重複しないよう
  注意する(何回目までの用語を扱ったかは `archiver/create/` 内の既存の
  `article.txt` を確認する)。
- 背番号(=連番)と基本プロフィールの背番号は必ず一致させる。
